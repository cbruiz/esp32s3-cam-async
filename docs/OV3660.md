# OV3660 Sensor Support

Initial OV3660 support for the ESP32-S3, using the existing asynchronous LCD-CAM/DMA capture pipeline.

## Implemented

- Sensor detection via SCCB (address `0x3C`, PID `0x3660`).
- 16-bit register addressing and basic sensor control.
- Initialization and register configuration ported from Espressif's `esp32-camera`.
- JPEG output at QVGA resolution (320×240).
- JPEG quality configuration.
- Asynchronous DMA capture using the existing `CameraCapture` and `JpegStreamParser`.
- Example programs:
  - `detect_ov3660` — sensor identification.
  - `capture_ov3660` — capture one JPEG frame and print hexadecimal data for host-side reconstruction.

## Hardware validation

Tested on a Freenove ESP32-S3 camera board (16 MB flash, 8 MB PSRAM) with an OV3660 sensor.

Successfully captured and reconstructed JPEG images at 320×240.

The capture example currently applies a manual white-balance preset to mitigate a green color cast.
